# 客戶需求工具

`needs/` 是獨立的客戶需求表。空污與熱交換計算已移到 `../calculator/`；風機選型在 `../fan-selection/`，原有 `../engineering/` 內部登入版保持獨立。

目前可使用「測試送出並查看推薦」：客戶資料只在本機表單中，測試推薦由 `preview.js` 的明確規則產生，不呼叫 AI、資料庫或郵件服務，也不會保存內容。可用虛構聯絡資料比較不同粉塵、酸鹼氣、VOC、油霧等條件。這是規則初篩，**不能代表未部署的正式 AI 結果或設備定型**。

正式送出仍由 `config.js` 的 API 位址控制。未配置受保護資料庫、AI 服務與郵件通知時按鈕停用；部署方法見 `../needs-api/README.md`。正式結果僅在後端保存需求後顯示。

本機測試：`node --test preview.test.cjs`；API 規則與欄位測試：在 `../needs-api/` 執行 `npm test`。
