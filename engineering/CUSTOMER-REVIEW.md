# 客戶現場初估版本複核

日期：2026-09-29。用途是建立可追溯的初步設計條件，逐項用客戶量測、粉塵分析及設備供應商資料替換範例。畫面上的有效位數不代表設備精度。

## 本次修正

- 熱側新增乾基標準風量／入口實際濕風量及入口相對濕度。未低於露點時不產生冷凝水，避免把所有廢氣都視為飽和。
- 基本條件新增密度基準：乾氣體分子量配合水蒸氣分壓，或直接使用混合氣平均分子量。實測密度優先。舊紀錄未含此選項時沿用舊的混合氣基準，不悄悄改變數據意義。
- 風管、旋風、袋濾、靜電、洗滌塔、活性碳及風機新增各自入口溫度、實際風量與密度。只改溫度時假設相同壓力、氣體組成及莫耳流量；加濕、冷凝、漏氣或反應後必須提供該處實際風量與密度。黏度仍為空氣近似，非空氣或高濕氣體需確認物性。
- 旋風可按粒徑質量分布加權，不再只能用一個代表粒徑推算全部粉塵。百分比必須合計 100%，依舊是分級曲線模型而非設備實測效率。
- 入口 PM 為零時，煙囪四項 PM 結果均為零，即使尚未填旋風實測效率。
- 風管紊流直接求解 Colebrook 方程；轉捩流仍拒絕提供確定壓損。HCl、SO₂、HF、NH₃、H₂S 及 NaOH 的名稱／分子量不一致會提示錯誤；其他藥劑仍須人工核對反應計量。
- 紀錄載入後會重新計算並列出物理條件錯誤，避免把「檔案讀取成功」誤當作「全部計算有效」。

## 獨立物性對照

以 [CoolProp 濕空氣物性模型](https://coolprop.org/fluid_properties/HumidAir.html) 8.0.0 的濕空氣焓、含濕比、比容與液態水焓，獨立計算入口氣體焓減去出口氣體及冷凝液焓，再比對網站。其濕空氣模型採 ASHRAE RP-1485 的實際氣體方法。

327 個有效案例：絕對壓力 80、101.325、120、150、200 kPa；入口 30、50、60、70、80、90、95、98°C；出口 15、25、40°C 且低於入口；入口相對濕度 30、60、100%。排除入口純水飽和壓 ≥ 總壓 98% 的點，部分排列不成立，故不是所有組合。對照僅使用空氣＋水、預設比熱及乾氣分子量。

| 比對項目 | 測試集合最大相對差 |
|---|---:|
| 乾基標準風量的熱負荷 | 1.24271% |
| 實際濕風量的熱負荷 | 1.17613% |
| 濕空氣密度 | 1.32456% |
| 每 kg 乾氣冷凝量（參考值 > 0.01 kg/kg） | 1.75730% |

90→40°C、101.325 kPa、入口飽和的原預設案例，熱負荷差約 −0.96%。這些是測試集合的比較結果，**不是整個系統、其他氣體或實體設備的誤差保證**。冷凝量接近零時相對誤差沒有實用意義，不套用表中的界限。

`thermal-reference.json` 保存獨立參考數值；`generate-reference.py` 可用 Python 與 CoolProp==8.0.0 重建。網站執行不需要 Python 或外部物性服務。

## 自動檢查與現場資料

47 項核心測試及 1,002 項本次複核通過，包含 981 次物性對照、21 項針對風量基準、濕度、設備工況、PSD、PM 零值、化學分子量、Colebrook 殘差與紀錄載入的回歸檢查。詳細結果見 [CUSTOMER-REVIEW-TESTS.txt](CUSTOMER-REVIEW-TESTS.txt) 與 [TEST-RESULTS.txt](TEST-RESULTS.txt)。網頁操作另見 [UI-TEST-RESULTS.md](UI-TEST-RESULTS.md)。

現場最需要先確認的是流量的實際／標準及乾／濕基準、溫度、絕對壓力、含水量、污染物濃度基準與粒徑分布。Nm³ 固定 0°C、101.325 kPa，不能直接代入其他標準溫度的流量。

設備尺寸與性能仍取決於濾材過濾速度、有效移動速度、HTU、藥劑利用率、吸附工作容量、熱交換 U、污垢、風機曲線及各段壓損。這些輸入缺少實測依據時，無法給出統一的小誤差承諾。尤其熱交換面積與 U 成反比，U 差一倍，面積就差一倍；活性碳容量法不是突破時間預測；簡化洗滌 NTU 假設氣相平衡濃度近零。

煙囪只計算流量、截面及 PM 質量／濃度，不包含法規排放標準、擴散模式或法定高度判定。兩套工具的條件分別維護，不會自動把熱交換的冷凝結果變成完整空污流程模擬。公開測試頁沒有存取限制；計算紀錄只在本機處理，尚無伺服器儲存。
